# Assignment 7: Protein Quantification and Differential Abundance Analysis

## Introduction

This assignment performs label-free, relative quantification of protein abundances for the publicly available PXD047095 dataset of *Methanococcus maripaludis*. The analysis identifies differentially abundant proteins across different growth conditions using quantification and statistical methods.

## Input Data

- **mzML files**: Proteomics mass spectrometry data files (MS1 and MS2 scans)
- **Merged CSV file**: Protein database search results from Week 6 lab (generated by MSFragger)

These input files are located on the Oedipus server.

## Running the Code

### Step 1: Quantification (PXD047095_quant.py)

This script performs label-free quantification using the input mzML files and the merged database search results CSV file.

**Command:**
```bash
python PXD047095_quant.py /path/to/mzML_files/ /path/to/merged_results.csv
```

**Arguments:**
- **First argument**: Directory containing the mzML files
- **Second argument**: Path to the merged CSV file from Week 6 MSFragger results

**Output files generated:**
- `BayesianFoldChangeAnalysis.tsv`: Contains log2 fold changes and posterior error probabilities (PEP) for condition comparisons with "Culture 0" as the control

### Step 2: Volcano Plots (volcano_plot.py)

This script creates volcano plots comparing each test condition ("Culture 1", "Culture 2", "Culture 8") against the control condition ("Culture 0").

**Command:**
```bash
python volcano_plot.py BayesianFoldChangeAnalysis.tsv
```

**Output files generated:**
- `Culture_1_volcano_plot.html`: Interactive volcano plot for Culture 1 vs Culture 0
- `Culture_2_volcano_plot.html`: Interactive volcano plot for Culture 2 vs Culture 0
- `Culture_8_volcano_plot.html`: Interactive volcano plot for Culture 8 vs Culture 0

These plots display differentially abundant proteins based on log2 fold changes (x-axis) and -log10 posterior error probability (y-axis).

### Step 3: UpSet Plot Analysis (Upset_Plot.py)

This script creates an UpSet plot showing the intersection and overlap of differentially abundant proteins across the three condition comparisons.

**Command:**
```bash
python Upset_Plot.py BayesianFoldChangeAnalysis.tsv
```

**Output files generated:**
- `DA_Proteins_Upset_Plot.png`: Visualization of the intersection of differentially abundant proteins across all three condition comparisons
- `DA_Proteins_Summary.csv`: Summary file listing:
  - Differentially abundant proteins across conditions
  - Which conditions show differential abundance for each protein
